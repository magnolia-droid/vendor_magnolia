# MagnoliaDroid Vendor Configuration & Overlays

This repository contains vendor-level apps, overlays, and system enhancements for **MagnoliaDroid**:
- **Smart Dock**: Desktop environment, taskbar and window manager.
- **Pixel Launcher**: Handheld and touch-oriented clean tablet UI.
- **libndk bridge integration**: Native bridge configuration for ARM/ARM64 translation on x86_64.
- **Magisk Integration**: Pre-integrated root & Zygisk capabilities.
